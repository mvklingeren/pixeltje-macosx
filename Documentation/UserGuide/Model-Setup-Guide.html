Set up FLUX.2 Klein 9B FP8

Pixeltje Pipeline loads Core AI model packages from your Mac. The app download contains the example workflows and conversion recipe, but no model weights. This guide builds the regular 1024 × 1024 package and, if you supply the adapter, the Real HD 2K variant.

1. Prepare your Mac

Use an Apple Silicon Mac with the macOS and Xcode versions required by this Pixeltje Pipeline release. Install uv, the Hugging Face CLI (hf), and Git. Allow ample free disk space for the source checkpoints, intermediate exports, and final packages. Keep the build workspace until both packages are complete.

Open the publisher's 9B FP8 page, sign in, and accept its access conditions in your own account. Then authenticate the CLI in Terminal:

hf auth login

The 9B weights use the FLUX Non-Commercial License. Qwen3-8B-FP8 and the 4B VAE are separate publisher downloads. The setup command obtains them directly from Qwen and Black Forest Labs. Pixeltje does not collect your Hugging Face token.

2. Build the regular 9B package

In Terminal, run the command bundled beside this guide. The example assumes the app is in /Applications; use the app's actual path if you installed it elsewhere.

"/Applications/Pixeltje Pipeline.app/Contents/Resources/ModelSetup/setup-flux2-klein-9b.command"

The command clones the pinned Apple Core AI conversion tools, downloads only the required publisher files, verifies the reviewed weight hashes, exports the components, and assembles a self-contained package at ~/.pixeltje/models/FLUX.2-klein-9B-fp8-1024. It does not require ~/coreai-models. To use other locations, pass --workspace and --model-library with full directory paths. For help, pass --help.

3. Optionally build the Real HD 2K variant

Download HighDetail.safetensors yourself from the Real HD 2K page. This example requires the reviewed file with SHA-256 108c649190f0953852feb15dad3d8ef8821753814a386ae46006d6949f722616. Then run:

"/Applications/Pixeltje Pipeline.app/Contents/Resources/ModelSetup/setup-flux2-klein-9b.command" \
  --variant real-hd-2k --adapter "$HOME/Downloads/HighDetail.safetensors"

This creates ~/.pixeltje/models/FLUX.2-klein-9B-fp8-1024-real-hd-2k with the adapter fused into the denoiser. The name “2K” belongs to the adapter; this workflow generates at 1024 × 1024. Use --variant both with the same adapter to build both packages together.

4. Open a workflow

In Pixeltje Pipeline, choose File → Show Example Workflows to see the bundled examples in Finder. Then choose File → Open… in Pixeltje Pipeline and select either image_flux2_klein_text_to_image_9b_fp8_coreai.pixpipeline.json or image_flux2_klein_text_to_image_9b_real_hd_2k_coreai.pixpipeline.json. Choose the matching directory above when the editor asks for a Model Package. Use Save As… to save your edited copy outside the app bundle.

What is stored where?

The build workspace defaults to ~/Pixeltje Model Build; it holds the Apple tools, publisher checkpoints, and intermediate exports. The app reads only the final Core AI package under ~/.pixeltje/models. The workflows link to those packages; they never embed model weights. You can back up or move a complete final package, then select its new directory again in Pixeltje Pipeline.

Source: Apple coreai-models. For build failures, keep the Terminal error text. Downloads can be retried; if an export is reported as incomplete, move that intermediate export directory aside before retrying.
